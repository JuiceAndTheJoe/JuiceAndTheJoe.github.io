Info

A collection of projects made for Märtha. Each project has its own folder, with room for more.

This page isn't linked from the main site yet. It is not private: published files can still be reached by their direct URLs.

Project files

The wheel is a standalone HTML page. The designer includes its editable React, TypeScript, and Vite source alongside the static version linked above.

Updating the designer

From cross-stitch-designer/:

npm ci
npm run dev

Run npm run build to refresh the static version, then commit the source changes and the resulting dist/ files. Assets use relative paths; installed dependencies stay ignored.

Adding projects

Add a descriptive, lowercase, hyphen-separated folder alongside the existing projects. Keep its source, assets, and configuration together. Use index.html for standalone pages and a project-local dist/ folder for built pages, then add a link here and update the project notes.
